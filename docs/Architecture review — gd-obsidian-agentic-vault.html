Defects found while exploring

Not architecture, but each was confirmed in the code and none is covered by a test.

  • vault.ts:240 uses API_BASE, which is defined nowhere, so session backup from the Control Panel always returns "API_BASE is not defined".
  • query.py:340 references sub.distance; the sqlite-vec search path can never succeed.
  • server.js:204 guards with startsWith(vaultPath), which also accepts a sibling directory such as vault-backup.
  • server.js:436-444 builds a shell string for exec; POST /api/sessions/backup writes to any path the caller names. The server listens on 0.0.0.0.
  • backend/venv (6,647 files) and __pycache__ are tracked in git, against the "no committed build artifacts" convention.

Top recommendation

Start with the Vault layout module

It is the smallest change, the drift is already real, and candidates 3, 4, 6 and 7 all need it. It also turns the Left Hemisphere read-only rule from prose into something a test can check.
